API & JSON

  • JSON adalah format data ringan yang sering dipakai API.
  • PHP mengubah array menjadi JSON dengan json_encode().
  • API memungkinkan komunikasi antar aplikasi (web, mobile, service).
  • Header Content-Type: application/json menandai respons JSON.

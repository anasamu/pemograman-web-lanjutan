Pemrograman Web Lanjutan

Fungsi & Array

  • Fungsi membuat kode modular dan dapat dipakai ulang (reusable).
  • Array menyimpan banyak data dalam satu variabel.
  • Array numerik memakai indeks angka; array asosiatif memakai kunci bernama.
  • Prinsip DRY (Don't Repeat Yourself) menjaga program tetap efisien.

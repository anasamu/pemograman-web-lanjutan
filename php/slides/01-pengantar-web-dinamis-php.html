Pemrograman Web Lanjutan

Pengantar Web Dinamis & Dasar PHP

  • Web dinamis menghasilkan konten berdasarkan request pengguna.
  • Web server (Apache/Nginx) melayani halaman ke browser.
  • PHP adalah bahasa server-side yang dieksekusi sebelum hasil dikirim ke browser.
  • Sintaks dasar: variabel, echo, dan file dengan ekstensi .php.

# Contoh Praktikum Per Pertemuan

Setiap file menampilkan **hasil eksekusi** dan **kode bersih** (tanpa wrapper berlapis).

## Daftar pertemuan

| File | Topik |
|---|---|
| pertemuan-01-php-dasar.php | PHP dasar |
| pertemuan-02-kondisi-dan-perulangan.php | if/else & loop |
| pertemuan-03-fungsi-dan-array.php | Fungsi & array |
| pertemuan-04-form.php | Form GET/POST |
| pertemuan-05-mvc.php | Konsep MVC |
| pertemuan-06-routing-controller.php | Routing |
| pertemuan-07-database.php | Koneksi MySQL |
| pertemuan-08-crud.php | CRUD |
| pertemuan-09-auth.php | Session login |
| pertemuan-10-upload.php | Upload file |
| pertemuan-11-api-json.php | API JSON |
| pertemuan-12-ajax.php | AJAX |
| pertemuan-13-oop.php | OOP |
| pertemuan-14-eloquent.php | Eloquent (simulasi) |
| pertemuan-15-proyek.php | Skeleton proyek |
| pertemuan-16-presentasi.php | Outline presentasi |

## Pendukung

- `koneksi-db.php` — tes koneksi
- `crud-sederhana.php` — CRUD ringkas
- `form-login.php` — login session
- `upload-file.php` — upload berkas

## Cara pakai

1. Jalankan Docker Compose.
2. Buka http://localhost:8080
3. Pilih pertemuan → Contoh.

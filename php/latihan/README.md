# Latihan Praktikum untuk Mahasiswa

Dokumen ini berisi latihan mandiri yang dapat dikerjakan mahasiswa sebagai tugas praktik per pertemuan.

## Tujuan latihan
- Menguatkan konsep PHP dasar.
- Melatih logika pemrograman dan pemecahan masalah.
- Membiasakan penggunaan form, fungsi, array, dan database.
- Menyiapkan mahasiswa untuk projek akhir web dinamis.

## Petunjuk umum
1. Buka folder `PRAKTIKUM/php/` atau `PRAKTIKUM/latihan/`.
2. Buat file sesuai nomor pertemuan.
3. Jalankan melalui browser dengan URL lokal.
4. Simpan hasil latihan sesuai format yang diberikan.
5. Tulis komentar singkat untuk menjelaskan logika program.

## Jadwal latihan

| Pertemuan | Topik | Jenis tugas |
|---|---|---|
| 1 | Pengantar PHP | Program sederhana |
| 2 | Logika dan perulangan | Program keputusan & looping |
| 3 | Fungsi dan array | Manipulasi data |
| 4 | Form handling | Form GET/POST |
| 5 | Laravel & MVC | Struktur aplikasi |
| 6 | Routing & Controller | Peta rute dan controller |

## Ketentuan penilaian
- Kerapihan kode: 20%
- Fungsi program: 40%
- Kejelasan logika: 20%
- Presentasi hasil: 20%

---

Mahasiswa diharapkan mengerjakan latihan secara mandiri dan mendiskusikan hasilnya saat praktikum berlangsung.
